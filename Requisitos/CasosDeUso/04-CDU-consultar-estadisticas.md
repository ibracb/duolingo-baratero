# Consultar estadísticas

**Actor principal:** Usuario estudiante
**Objetivo:** Mostrar el tiempo de uso, la mejor racha y otros indicadores de progreso.  
**Precondiciones:**  

1. El usuario debe estar registrado.

**Pasos:**

1. El usuario inicia sesión.
2. El usuario solicita consultar sus estadisticas.
3. El sistema calcula sus estadísticas.
4. El sistema muestra sus estadisticas.

**Postcondiciones:**

1. El usuario visualiza sus estadísticas y puede tomar decisiones en función de ellas.
