### Agregar nuevos tipos de preguntas

**Actor principal:** Usuario creador  
**Objetivo:** Permitir la incorporación de nuevas preguntas en un curso ya creado.  

**Precondiciones:**  
1. El usuario debe estar registrado en la aplicación.  
2. El usuario debe tener al menos un curso creado.  

**Pasos:**  
1. El usuario inicia sesión en la [ventana de inicio](../Ventanas/VentanaInicio.png).
2. El usuario accede a la [ventana principal](../Ventanas/VentanaPrincipal-UsuarioCreador.png).
2. El usuario selecciona el curso que desea modificar en la ventana principal
3. El usuario accede a la ventana [modicar curso](../Ventanas/VentanaCreaTuCurso.png).
3. El usuario presiona el botón "Añadir pregunta".  
4. El usuario elige el tipo de pregunta en la ventana [ElegirPregunta](../Ventanas/VentanaElegirPregunta.png).  
5. El usuario accede a la ventana [CrearPreguntaOpciones](../Ventanas/VentanaCrearPreguntaOpciones.png).  
6. El usuario completa los campos requeridos.  
7. El usuario presiona el botón "Guardar", regresando a la ventana [ModificarCurso](../Ventanas/VentanaCreaTuCurso.png).  

**Flujos alternativos:**  
- **05a.** El usuario accede a la ventana [CrearPreguntaImagenes](../Ventanas/VentanaCreaPreguntaImagenes.png).  
- **06a.** Vuelve al paso 6.  
- **05b.** El usuario accede a la ventana [CrearPreguntaAudio](../Ventanas/ventanacre).  
- **06b.** Vuelve al paso 6.  
- **05c.** El usuario accede a la ventana [crearPreguntaFlashcard](../Ventanas/VentanaCrearPreguntaFlashcard.png).  
- **06c.** Vuelve al paso 6.  

**Postcondiciones:**  
1. El usuario añade una pregunta a uno de sus cursos.
